# API 批量检测器

本地网页工具。输入多组 `baseurl` 和 `apikey`，并发验证，直接显示哪些实际可用。**默认针对 OpenAI 兼容 API，不是 Anthropic 原生 Messages 或 Gemini 原生接口检测器。**

## 1. 启动

Windows：先完整解压压缩包，再双击 `启动.bat`（或 `START.bat`）。程序会自动打开本地网页。

* 需要 Node.js 22 或更高版本，不需要 `npm install`，没有第三方依赖。
* 在制作工具的这台电脑上已检测到 Node.js 24.15.0。
* 启动脚本先使用 PATH 中的 Node，找不到时尝试本机 `D:\AI\node\node.exe`。
* 如果没有自动打开浏览器，请复制终端里显示的 `http://127.0.0.1:端口` 地址。
* 不要直接双击 `public/index.html`，它必须由本地服务提供。
* 终端按 Ctrl+C 结束服务。每次启动使用随机空闲端口，避免端口冲突。

命令行（Windows / macOS / Linux）：

    node server.mjs

不自动打开浏览器：`node server.mjs --no-open`。

## 2. 输入格式

每行一组，格式如下（示例为占位内容，不能用于真实调用）：

    baseurl:https://api.example.com/v1;apikey:sk-你的密钥
    baseurl:https://second.example.com/v1;apikey:sk-另一把密钥

* 分隔符支持英文 `;` 和中文 `；`，字段名不区分大小写。
* URL 必须带 `https://`。HTTP 默认拒绝，需要主动勾选「允许 HTTP 明文传输」。
* 如果只填 `https://example.com`，自动补 `/v1`。
* 已提供的自定义路径会保留；末尾斜杠会移除。
* 不要填写 `/chat/completions`、`/responses` 或 `/models` 完整地址，填它们前面的接口根路径。
* 不接受含用户名、密码、查询参数或 `#` 片段的 URL。
* 忽略空行和以 `#` 开头的注释行，相同 URL + 密钥会自动去重。
* 单次最多 500 组。

## 3. 验证方式

1. **模型名留空**：请求对应地址的 `/models`，从列表中筛选最多 3 个可能的文本模型。优先匹配 mini / flash / haiku / small 等名称，但这只是名称启发式，不保证最低价格，也不保证模型适配。
2. **填写模型名**：跳过 `/models`，直接测试该模型。对于不开放模型列表的平台，应填写平台明确支持的模型名。
3. 默认「自动」模式先测试 `/chat/completions`；遇到可继续尝试的兼容性/模型错误时再测试 `/responses`。也可固定其中一种接口。
4. 测试请求内容为 `Reply with OK.`，输出 token 上限设为 64。只有收到非空文本回复，才标记「可用」。
5. 老接口明确拒绝 `max_completion_tokens` 时，会以 `max_tokens` 重试一次。
6. 遇到鉴权失败、权限不足、额度不足、限流、网络异常、超时、重定向或 5xx 时，不继续尝试更多模型，避免无意义请求。

**注意费用**：这不是零成本检查。默认自动模式单组可能依次请求模型列表、3 个模型 × 2 种协议，并包含必要的参数兼容重试；通常首次成功即停止。指定模型 + 固定协议可减少请求数。费用由服务商决定。

推理模型可能在 64 个输出 token 内不返回可见文本，这时显示「未确认可用」，不把它误判为已验证可用。可换已知支持普通文本输出的模型复核。

## 4. 怎么看结果

| 结果  | 含义  |
| --- | --- |
| 可用  | 本次所测模型与接口实际返回了非空文本 |
| 鉴权失败 | 接口返回 401，可能是密钥无效、过期或认证方式不兼容 |
| 权限不足 | 接口返回 403，可能是模型权限、IP 限制或网关策略，不等于整把密钥失效 |
| 额度 / 余额不足 | 服务端错误信息指向额度或余额不足 |
| 限流  | 接口返回 429 且未明确指向余额不足，可以稍后降低并发重试 |
| 网络异常 / 超时 | 当前网络无法正常完成请求，不能据此认定密钥无效 |
| 接口 / 模型不支持 | 所测路径或模型未成功，请核对接口根路径和模型名 |
| 未确认可用 | 缺少可测模型、模型列表不可用，或成功状态码没有有效文本 |
| 响应不兼容 | 返回了 HTML 等不符合预期的响应，例如网站首页或 WAF 页面 |
| 重定向已拦截 | 服务端让请求跳转到其他地址，工具不会携带密钥跟随 |
| 输入有误 | 格式不正确或 URL 未通过检查 |

可用项排在最前，可以选择「只看可用」。每行有请求详情与总耗时；总耗时包含模型列表查询和重试，不是纯模型延迟。

* **复制可用项**：明确确认后，将成功项按原始输入格式复制，包含完整密钥，便于继续使用。
* **导出脱敏 CSV**：不包含完整密钥；能用 Excel 打开，并对服务端返回内容做公式注入防护。
* **停止**：中止本地等待和继续调度，保留已完成结果。已到达服务商的请求仍可能被处理或计费；未返回结果的项目视为未验证。
* **清空**：清除页面输入和结果，不会自动清除系统剪贴板或已导出的文件。

## 5. 隐私与安全边界

* 只监听 `127.0.0.1`，不开放给局域网其他设备。
* 使用随机本地校验令牌，并检查 Host / Origin，拒绝其他网页发起的检测提交。
* 没有遥测，不使用第三方检测平台，不加载 CDN 资源。
* 输入和密钥在浏览器与本地 Node 进程内存中处理，不写入本地日志或结果文件，也不使用 localStorage。
* 每把密钥会通过 Authorization 请求头发到你为它填写的 Base URL。这是验证所必需的；请自行确认该域名可信。
* 不自动跟随重定向；不关闭 TLS 证书验证。HTTP 只有主动勾选后才允许。
* 默认结果与服务端错误信息脱敏。主动「复制可用项」会将完整密钥放入系统剪贴板，可能被剪贴板同步/管理软件保存。
* **并不保证对恶意服务商的绝对保密**：对方本就收到密钥，若它编码或变换后回显，通用脱敏不能识别所有情况。
* 关闭、清空并不保证操作系统内存、浏览器插件、崩溃转储或剪贴板历史安全擦除。敏感场景请使用可信设备和浏览器。
* 不内置代理或代理认证配置；浏览器能访问某服务，不保证 Node 进程也能访问，必要时检查系统/网络环境。
* 只检查你自己或明确授权使用的密钥，不提供密钥搜索、猜测或生成功能。
* 「可用」只表示该地址接受该次请求并返回兼容文本，不证明平台确实运行了它声称的模型，也不证明密钥未来始终可用或所有模型都可用。

## 6. 测试与文件

运行本地模拟接口测试，无需真实密钥，不访问外部 API：

    node --test

文件：

* `server.mjs`：本机 HTTP 服务、请求校验、流式进度。
* `checker.mjs`：解析、并发检测、接口兼容与结果分类。
* `public/index.html`：中文网页界面。
* `test/checker.test.mjs`：模拟接口自动化测试。
* `START.bat` / `启动.bat`：Windows 启动入口。

测试使用的是本地模拟接口。未预置、也未用任何用户真实密钥执行外部付费调用。
